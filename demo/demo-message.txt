# DSH Tavern Renderer 全功能演示

> 把本文件全部内容作为一条「用户消息」粘贴发送（建议开一个新会话）。
> 发送后可以再发一条：{{getvar::mood}} / {{getvar::score}} / {{incvar::turn}}，观察变量在同一会话内持久。

## 01 身份宏（默认 Assistant / User，可用控制台 configure 注入真实名称）

我是 {{user}}，{{char}} 是我这边的主持人，当前角色是 {{role}}。
persona/description/scenario 在聊天里默认为空：{{persona}}｜{{description}}｜{{scenario}}
未知宏保持原样：{{unknown_macro_xyz}}

## 02 时间宏

{{date}}（{{weekday}}），本地 {{time}}；UTC {{isotime}} / {{isodate}}
多行效果：第一行{{newline}}第二行

## 03 变量（setvar/addvar 无输出，incvar 输出新值）

{{setvar::mood::calm}}{{setvar::score::10}}{{addvar::score::2}}
mood = {{getvar::mood}}，score = {{getvar::score}}，递增一次 = {{incvar::score}}，再读 = {{getvar::score}}

## 04 安全内联表达式 {{js::...}}

- {{js::1 + 2 * 3}}、{{js::(6 * 7) + 1}}、{{js::10 >= 5 ? "大" : "小"}}、{{js::user + " 说 " + char}}
- 变量参与：score = {{getvar::score}}，double = {{js::score * 2}}
- 越界被拒（无 eval，纯白名单解析器）：{{js::window.location}} 与 {{js:: 1 + }} 都会变成 [expression error]

## 05 行内格式

**粗体**、*斜体*、***粗斜体***、~~删除线~~、++下划线++、`行内代码`、\*转义星号\*、\_转义下划线\_

## 09 表格（对齐冒号会被忽略，单元格支持行内格式）

| 名称 | 类型 | 数值 |
| --- | :--- | ---: |
| HP | 生命 | 100 |
| MP | **魔力** | 42 |

## 10 代码围栏（语言类名保留，由 CSS 白名单放行）

```js
const answer = 6 * 7
console.log(answer)
```

注意：宏在 Markdown 之前求值，所以围栏里写 {{js:: 6 * 7 }} 显示出来也是 42。
